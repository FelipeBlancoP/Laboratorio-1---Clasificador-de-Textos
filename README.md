## Instrucciones

1. **Instalar Ollama**

2. **En CMD, ejecutar:**
```
ollama pull qwen2.5:1.5b
```

3. **Instalar librerias**\
Abrir una terminal en la carpeta base del proyecto, ejecutar:
```
pip install -r requirements.txt
```

4. **Ejecutar programa**\
En la misma terminal que el punto anterior:
```
python main.py
```
